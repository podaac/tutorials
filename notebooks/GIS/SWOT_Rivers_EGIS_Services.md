# Earthdata GIS SWOT Rivers Feature Services

The SWOT Rivers Feature Service is available in both the ArcGIS REST Endpoints and Open Geospatial Consortium (OGC) Endpoints.
This includes the full attribute table catalog and 'BASIC' which is a subset of the 'Basic' attributes.

The following are the available service endpoints for each SWOT Rivers version and type:

### SWOT_L2_HR_RiverSP_reach_vD (03/28/23 - Present; 1:5,000 - 1:10,000,000 zoom level extent)
[Feature Service](https://gis.earthdata.nasa.gov/portal/home/item.html?id=bcedc71373f04a75bbe3bbc465c07050)

[Map Image Service](https://gis.earthdata.nasa.gov/portal/home/item.html?id=e92a2ede7eed41808dfa607420b1459c)

[Web Feature Service (WFS)](https://gis.earthdata.nasa.gov/portal/home/item.html?id=07fefd476cb74ee08a2912d218c28db8)

[OGC Feature Layer](https://gis.earthdata.nasa.gov/portal/home/item.html?id=82f1018f181d4c87b7332070ce405c11) (Currently Unavailable)

### SWOT_L2_HR_RiverSP_reach_vD_BASIC (03/28/23 - Present; 1:5,000 - 1:10,000,000 zoom level extent)
[Feature Service](https://gis.earthdata.nasa.gov/portal/home/item.html?id=9e2609d5ff384ec69796ec1433b30390)

[Map Image Service](https://gis.earthdata.nasa.gov/portal/home/item.html?id=2559552dfb7546d88ad8df69e15f2bc5)

[Web Feature Service (WFS)](https://gis.earthdata.nasa.gov/portal/home/item.html?id=547731e6fcf441219608ae595200e54b)

[OGC Feature Layer](https://gis.earthdata.nasa.gov/portal/home/item.html?id=e82be6d44293457ca6efca32ecbfdcfa) (Currently Unavailable)

### SWOT_L2_HR_RiverSP_vC Retirement

SWOT vC EGIS services have been deprecated as of Dec 1, 2026 due to data products themselves having been retired Dec 1, 2026. See this data alert from more information: https://www.earthdata.nasa.gov/data/alerts-outages swot-version-d-reprocessing-complete-version-c-retired-december-1-2026

Users are encouraged to use the SWOT vD data and corresponding EGIS services.
